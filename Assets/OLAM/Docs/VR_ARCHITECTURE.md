# OLAM VR — «Живой Узбекистан» / Edutainment

Навигация: **Хаб пространств → раздел → подраздел (биом) → виртуальное пространство**.

```
OlamHub (карта пространств)
├── Природа → NatureDome (Купол: 5 биомов)
│   ├── Пустыни (Чўл)        → Biome_Desert
│   ├── Предгорья (Адыры)    → Biome_Adyr
│   ├── Горы (Тау)           → Biome_Mountains
│   ├── Высокогорья (Яйлау) → ChatkalNightTrail  (пилот)
│   └── Тугаи                → Biome_Tugai
├── Кухня  → Tandoor
└── История → ToprakKala
```

В биоме: **фильтр категорий** (деревья / травы / фауна) → **Эко-Сканер** (не срыв!) → голограмма (≤40 слов) → значок в **Гербарий**.

Данные: `EncyclopediaEntry` (+ статус Красной книги, «суперсила», подсказка интерактива) + `BiomeDefinition`.
