# OLAM — сайт проекта об Узбекистане

Одностраничный сайт совместного российско-узбекского образовательного проекта: интерактивные
виртуальные пространства о 14 регионах Узбекистана.

- Адрес: https://vlg2003dubtzov.github.io/OLAM/ (GitHub Pages, репозиторий `OLAM`, ветка `main`, корень).
- OLAM — отдельный проект. С образовательной платформой автора **РИОН** (`Рабочий стол\РИОН`)
  он почти не связан: сайт OLAM на РИОН не ссылается, обратная ссылка возможна только из
  будущих курсов узбекского языка.

## Как устроено

Сборки нет: `index.html`, `style.css`, `favicon.svg` и `404.html` публикуются как есть.
Текст правится прямо в `index.html`. Стиль OLAM — арка-портал, лазурит, бирюза,
Cormorant Garamond — живёт только здесь. У РИОН своя айдентика «Конструктив».

Посмотреть локально:

```
python -m http.server 8792
```

и открыть http://localhost:8792.

## Публикация

```
git add -A
git commit -m "Обновление"
git push
```

Сайт обновится через минуту-две.
